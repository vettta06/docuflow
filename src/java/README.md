## Требования

- JDK 21
- Apache Maven 3.10.1

## Сборка проекта

Открыть терминал в директории `src/java` и выполнить:

```bash
mvn clean compile
```

## Запуск программы

```bash
mvn exec:java "-Dexec.mainClass=docuflow.Main"
```

По умолчанию программа читает входные данные из файла `../test_data.json`. Для проверки на собственных входных данных можно изменить содержимое `../test_data.json` или передать путь к отдельному JSON-файлу через аргумент `exec.args`:

```bash
mvn exec:java "-Dexec.mainClass=docuflow.Main" "-Dexec.args=../my_test_data.json"
```

При использовании собственного файла необходимо сохранить структуру JSON и названия полей, ожидаемые программой.

## Входные данные

Используется файл `test_data.json`, содержащий:
- список организаций;
- список бухгалтеров;
- связи бухгалтеров с организациями;
- обязательные типы документов;
- загруженные документы.

Файл совпадает с входными данными процедурной реализации на Python.

## Ожидаемый результат

```text
Missing documents: [акт]
Accountant with the smallest workload: Иван Петров
```

Результат Java-программы сравнивается с результатом процедурной реализации Python на одинаковых входных данных.
